# Vilkårsversjoner

Hver gang vilkår, salgsvilkår, refusjonssiden, kapselsiden eller personvernerklæringen endres, lagres en kopi her med dato i filnavnet, og «Sist oppdatert» på siden settes til samme dato. Da kan vi vise hvilke vilkår som gjaldt da en kunde kjøpte et løft (datoen står på kvitteringen).
